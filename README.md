# محفظة يديرة | Yadira Wallet

نسخة أولى تجريبية لإدارة ميزانية شخصية بالدينار الليبي. مبنية بقالب Expo Router وReact Native وTypeScript مع خادم Express/tRPC وقاعدة البيانات المُدارة المتاحة للمشروع.

## ما يعمل في هذه النسخة

- إدخال صافي الدخل وضروريات الشهر والأقساط ومبالغ اختيارية للادخار والاستثمار.
- حساب محلي حتمي يُظهر العجز أو الفائض ويعطي الأولوية للضروريات والالتزامات.
- سجل دخل ومصروفات محلي محفوظ في SQLite.
- عند تفعيل موافقة المستخدم، يرسل التطبيق مدخلات الميزانية إلى `POST /api/budget/recommend`. الخادم يتحقق من المخطط ويحسب التوصية دون حفظ البيانات.
- عند عدم الموافقة أو انقطاع الشبكة، يحسب التطبيق محليًا ويعرض حالة الاتصال.
- تبديل الوضع الفاتح/الداكن وموافقة اختيارية على طلب التحليل الخادمي.
- لا ينفذ التطبيق أي خصم أو تحويل أو استثمار، ولا يوصي بأصل أو منتج استثماري.

## قاعدة الحساب

تجمع الاحتياجات الأساسية المسجلة مع أقساط الديون الإلزامية مرة واحدة، ثم تقارنها بصافي الدخل. إذا لم يغطِّ الدخل الإجمالي المطلوب، تعرض الخطة العجز وتبقي الادخار والاستثمار عند صفر. عند وجود فائض، لا تخصص أموالًا للادخار أو الاستثمار إلا من المبالغ الاختيارية التي أدخلها المستخدم، ويُصفّر الاستثمار إن لم يفعّل المستخدم رغبته فيه أو لم يُدخل أفقًا زمنيًا وتحمّلًا للمخاطر. هذا منطق حسابي حتمي وليس نموذج ذكاء اصطناعي أو توصية استثمارية شخصية.

## تشغيل التطبيق والخادم محليًا

المشروع يستخدم pnpm 9 كما هو مثبت في `package.json`. بعد تثبيت الاعتمادات في بيئة المشروع:

```bash
pnpm db:push
pnpm dev:server
pnpm dev:metro
```

في بيئة WebDev المُدارة، لا تشغّل العمليتين يدويًا بدل المنصة؛ يُعرّف API باسم `api` على المنفذ 3000 بأمر `pnpm dev:server`، وMetro باسم `metro` على المنفذ 8081 بأمر `pnpm dev:metro` من خلال `webdev.config` لمسار `runtime/dev-commands`. عنوان API في التطبيق يأتي من إعداد Expo الذي يوفره القالب، ولا يُكتب عنوان جهاز دائم في الشيفرة.

مسارا API الأساسيان:

- `GET /api/health` لفحص الخدمة.
- `POST /api/budget/recommend` لاستقبال مدخلات التوصية وإرجاع خطة محسوبة؛ المدخلات لا تُكتب في قاعدة البيانات.

## حدود النسخة الأولى

تُعرض الواجهة أساسًا بالعربية وتدعم ترجمة إنجليزية للعناصر الشائعة مع زر تبديل؛ بعض رسائل الخادم والنصوص التخصصية ما زالت عربية. هذه النسخة لا تتضمن نموذج ذكاء اصطناعي توليديًا أو محادثة مالية، حسابات وتسجيل دخول، مزامنة متعددة الأجهزة، تشفير ملف SQLite أو PIN/قياسات حيوية، نسخة احتياطية، تصدير تقارير PDF/Excel، أسعار صرف أو عملات أخرى، تذكيرات، ولا تتبع استثمارات فعلية. لا تستخدم بيانات حقيقية حساسة قبل إكمال ضوابط التشفير والقفل وسياسة الخصوصية. موافقة API تعني إرسال أرقام الملف للخادم بطلب التحليل؛ لا توجد مزامنة أو حفظ مركزي لهذه البيانات.

## بناء APK

المشروع مهيأ كـ Expo Mobile. يتم طلب Android APK/AAB من لوحة WebDev بعد حفظ المصدر والإعدادات. لا يحتوي هذا التسليم على ملف APK مُبنى؛ يجب عدم اعتباره موجودًا قبل نجاح مهمة البناء الفعلية. قد تنطبق تكاليف حسب خطة WebDev أو استخدام موارد الخادم المُدارة، ولا تستخدم النسخة خدمات استثمار أو معاملات مالية خارجية.
